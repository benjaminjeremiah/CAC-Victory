# CAC Victory District Church Website

Welcome to the CAC (Christ Apostolic Church) Victory District official website.

## About Us
Christ Apostolic Church Victory District is a community of believers dedicated to spreading the Gospel and serving our community with love, faith, and dedication.

## Features
- Information about our church and mission
- Service times and schedules
- Upcoming events and activities
- Contact information and location
- Photo gallery
- News and announcements

## Getting Started
This website is built with HTML, CSS, and JavaScript for easy maintenance and scalability.

## Deployment
This site is hosted on GitHub Pages and is automatically deployed when changes are pushed to the main branch.

## Hosting
**Free Hosting:** GitHub Pages
**Domain:** benjaminjeremiah.github.io/CAC-Victory

## How to Enable GitHub Pages
1. Go to Repository Settings
2. Scroll to GitHub Pages section
3. Select 'main' branch as source
4. Your site will be live in minutes!
